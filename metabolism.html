乙酰 CoA枢纽●2025 简（来源去路）

⬇ 来源（从哪来）

  • 糖：葡萄糖 → 丙酮酸 →（丙酮酸脱氢酶复合体，线粒体）→ 乙酰 CoA
  • 脂：脂肪酸 β-氧化硫解、甘油氧化、酮体（肝外利用时）
  • 氨基酸：生酮/生糖兼生酮氨基酸脱氨基后生成
  • 奇数碳脂肪酸 → 丙酰 CoA → 琥珀酰 CoA → 间接入 TCA 补充

⬆ 去路（到哪去）

  • 三羧酸循环彻底氧化（主要去路，供能）
  • 合成脂肪酸、胆固醇、酮体的共同原料
  • 参与乙酰化反应（组蛋白乙酰化等）
  • ⚠️ 不能作糖异生原料（丙酮酸脱氢酶不可逆）
口诀 / 提示｜『来源最广、去路最忙』：糖、脂、氨基酸三大营养素在此汇合——2025 真题直接考来源去路
丙酮酸枢纽●真题高频

⬇ 来源（从哪来）

  • 葡萄糖糖酵解终产物（胞液）
  • 乳酸脱氢（乳酸 ⇌ 丙酮酸，Cori 循环的一环）
  • 丙氨酸转氨基（葡萄糖-丙氨酸循环）
  • 糖原分解的中间环节

⬆ 去路（到哪去）

  • 入线粒体 →（丙酮酸脱氢酶复合体）→ 乙酰 CoA + CO₂ + NADH（不可逆！）
  • 加 CO₂ →（丙酮酸羧化酶，生物素）→ 草酰乙酸（糖异生第一步）
  • 胞液中乳酸脱氢酶 → 乳酸（无氧/缺氧供能）
  • 丙氨酸转氨酶 → 丙氨酸（运氨形式之一）
口诀 / 提示｜一分二看氧：有氧走乙酰 CoA，无氧变乳酸，饥饿肝里走糖异生
葡萄糖-6-磷酸（G6P）枢纽◐2024 简（磷酸戊糖途径）

⬇ 来源（从哪来）

  • 葡萄糖磷酸化（己糖激酶 / 肝葡萄糖激酶）
  • 糖原分解（糖原磷酸化酶 → G1P → G6P）
  • 糖异生终末产物（葡萄糖-6-磷酸酶的上一步）

⬆ 去路（到哪去）

  • 糖酵解 → 产能
  • 磷酸戊糖途径 → NADPH + 核糖-5-磷酸（关键酶 G6PD）
  • 葡萄糖-6-磷酸酶水解 → 释放入血补血糖（只肝肾有，肌糖原不能升血糖）
  • 糖原合酶 → 合成糖原
口诀 / 提示｜『G6P 是血糖的十字路口』——五个方向全凭关键酶分流
α-酮戊二酸枢纽●2022 问、2018-19 简

⬇ 来源（从哪来）

  • 三羧酸循环：异柠檬酸脱氢（异柠檬酸脱氢酶，脱氢+脱羧）
  • 谷氨酸氧化脱氨的逆反应（α-酮戊二酸 ⇌ 谷氨酸，转氨枢纽）

⬆ 去路（到哪去）

  • TCA 中 →（α-酮戊二酸脱氢酶系）→ 琥珀酰 CoA
  • 加氨基 → 谷氨酸（联合脱氨基的核心配对物）
  • 添补反应（anaplerosis）：氨基酸碳架回补 TCA 中间物
  • 谷氨酰胺、GABA、脯氨酸等合成的碳骨架
口诀 / 提示｜『转氨的万能配角』：几乎每个转氨酶都拿它和氨基酸配对
草酰乙酸枢纽◐2020 问（TCA 全过程）

⬇ 来源（从哪来）

  • 苹果酸脱氢（TCA 最后一步）
  • 丙酮酸羧化（丙酮酸羧化酶，生物素）——糖异生关键
  • 天冬氨酸转氨基（⇌ 天冬氨酸，尿素循环供氮）
  • 奇数碳脂肪酸 → 琥珀酰 CoA → 苹果酸 → 草酰乙酸

⬆ 去路（到哪去）

  • 与乙酰 CoA 缩合 → 柠檬酸（柠檬酸合酶，TCA 起点）
  • PEP 羧激酶 → 磷酸烯醇式丙酮酸（糖异生）
  • 转氨基 → 天冬氨酸（尿素循环的第二个氮源）
口诀 / 提示｜糖异生和 TCA 共用它；天冬氨酸是它的「氨形」
NADH / FADH₂枢纽●2023 问（20 分，呼吸链）

⬇ 来源（从哪来）

  • NADH：糖酵解（胞液）、丙酮酸脱氢、TCA 三次脱氢（异柠檬酸/α-KG/苹果酸）、β-氧化
  • FADH₂：琥珀酸脱氢（TCA）、脂肪酸 β-氧化第一步、甘油-3-磷酸/脂酰 CoA 穿梭系

⬆ 去路（到哪去）

  • NADH 氧化呼吸链（复合体Ⅰ→Ⅲ→Ⅳ），P/O ≈ 2.5 ATP
  • FADH₂ 走琥珀酸氧化呼吸链（复合体Ⅱ→Ⅲ→Ⅳ），P/O ≈ 1.5 ATP
  • NADPH（还原性生物合成、维持谷胱甘肽还原态）——注意 NADPH 与 NADH 分工不同
口诀 / 提示｜『一个走Ⅰ门，一个走Ⅱ门』：NADH 从复合体Ⅰ进，FADH₂ 从Ⅱ进——ATP 差 1 个
糖代谢 3 种
葡萄糖（血糖）●2022/2024/2025（血糖调节）

⬇ 来源（从哪来）

  • 食物糖消化吸收（入血主渠道）
  • 肝糖原分解（肝糖原 → G6P → 葡萄糖-6-磷酸酶 → 葡萄糖）
  • 糖异生（乳酸、甘油、生糖氨基酸、丙酸）
  • 其他单糖（果糖、半乳糖、甘露糖）转化

⬆ 去路（到哪去）

  • 氧化供能（有氧氧化 / 无氧酵解）
  • 合成糖原储存（肝、肌）
  • 磷酸戊糖途径 → 转变为核糖 + NADPH
  • 转为脂肪、非必需氨基酸
  • 超过肾糖阈 → 随尿排出
口诀 / 提示｜来源四路、去路五条；『胰岛素唯一降糖，胰高肾上腺素糖皮质升糖』
乳酸○大纲必须掌握

⬇ 来源（从哪来）

  • 骨骼肌剧烈运动无氧酵解
  • 红细胞（无线粒体，唯一供能方式靠糖酵解产乳酸）
  • 视网膜、皮肤等正常酵解产物

⬆ 去路（到哪去）

  • 乳酸循环（Cori 循环）：入肝 → 糖异生 → 葡萄糖回输肌肉
  • 心肌、肝氧化利用（LDH 逆反应 → 丙酮酸入 TCA）
  • 肾排出（极少）
口诀 / 提示｜『肌肉产、肝里变糖』——Cori 循环本身耗能（肝用 6 ATP，肌净得 2 ATP）
柠檬酸◐TCA 必考环节

⬇ 来源（从哪来）

  • 草酰乙酸 + 乙酰 CoA →（柠檬酸合酶）缩合
  • 线粒体内 TCA 第一步产物

⬆ 去路（到哪去）

  • 异柠檬酸 → α-酮戊二酸（异柠檬酸脱氢酶，限速）
  • 出线粒体 → 裂解回乙酰 CoA（脂肪酸合成的原料转运：柠檬酸-丙酮酸循环）
  • 激活乙酰 CoA 羧化酶（脂肪合成的变构激活剂）
口诀 / 提示｜『TCA 的开门人，也是脂肪合成的运料车』
脂类代谢 5 种
脂肪酸（游离 FFA）●2021 问、2025 问（β-氧化）

⬇ 来源（从哪来）

  • 脂肪动员：甘油三酯 →（HSL 激素敏感脂肪酶，限速）→ FFA + 甘油
  • 食物中甘油三酯消化水解（胰脂肪酶 + 辅脂酶，胆汁酸盐乳化）
  • 脂肪合成（乙酰 CoA 羧化酶 → 丙二酰 CoA → 软脂酸）
  • 磷脂、鞘脂降解

⬆ 去路（到哪去）

  • 活化（耗 2 高能键）→ 肉碱转运（CPT-Ⅰ 限速，丙二酰 CoA 抑制）→ 线粒体 β-氧化 → 乙酰 CoA
  • 再酯化合成甘油三酯、磷脂
  • 奇数碳脂肪酸 → 丙酰 CoA → 琥珀酰 CoA（可糖异生）
  • 与白蛋白结合经血运输供全身
口诀 / 提示｜β-氧化四步口诀：『脱氢、加水、再脱氢、硫解』；软脂酸 106 ATP（新算法）
甘油◐真题多次涉及

⬇ 来源（从哪来）

  • 脂肪动员：HSL 水解甘油三酯的伴随产物
  • 糖酵解中间物 DHAP 还原（脂肪合成的最后一步）
  • 食物中甘油三酯消化

⬆ 去路（到哪去）

  • 甘油激酶（肝、肾）→ α-磷酸甘油 → DHAP → 糖异生原料
  • → 完全氧化供能
  • 再酯化参与甘油三酯合成
  • ⚠️ 脂肪细胞缺乏甘油激酶，甘油必须运回肝利用
口诀 / 提示｜『脂肪不能变糖，甘油例外』——三大营养素互转的经典考点
酮体（乙酰乙酸、β-羟丁酸、丙酮）◐大纲必须掌握

⬇ 来源（从哪来）

  • 肝线粒体：2 分子乙酰 CoA →（HMG-CoA 合酶，关键酶）→ 乙酰乙酸 → β-羟丁酸 / 丙酮
  • 原料唯一：乙酰 CoA（来自脂肪酸 β-氧化）

⬆ 去路（到哪去）

  • 肝外利用：心、肾、骨骼肌、饥饿时脑 → 乙酰乙酰 CoA → 乙酰 CoA → 氧化供能
  • 丙酮经肺呼出（烂苹果味）
  • 过多 → 酮血症、酮尿、酮症酸中毒（糖尿病急症）
口诀 / 提示｜口诀：『肝内合成肝外用，肝外氧化回乙酰；HMG-CoA 合酶是关键』
胆固醇◐2018-19 问、2024 判

⬇ 来源（从哪来）

  • 自身合成：肝胞液/内质网，18 乙酰 CoA + NADPH + ATP，关键酶 HMG-CoA 还原酶（他汀靶点）
  • 食物消化吸收（乳糜微粒运送）

⬆ 去路（到哪去）

  • 转化为胆汁酸（主要去路，约占 40%，7α-羟化酶限速）
  • 合成类固醇激素（肾上腺皮质、性腺）
  • 转化为维生素 D₃（皮肤经紫外线）
  • 构成生物膜、酯化储存于脂蛋白（LDL 运往肝外）
  • 随胆汁排出（部分）
口诀 / 提示｜『一原料三去路』：HMG-CoA 还原酶是开关，胆汁酸是主出口，LDL 受体负反馈
血浆脂蛋白（CM / VLDL / LDL / HDL）○2024 判、2025 简（CM）

⬇ 来源（从哪来）

  • CM：小肠黏膜合成，装外源性甘油三酯（apoB48）
  • VLDL：肝细胞合成，装内源性甘油三酯（apoB100）
  • LDL：VLDL 代谢中甘油三酯被 LPL 水解后剩余（胆固醇为主）
  • HDL：肝、小肠新生，表面获 apoAⅠ

⬆ 去路（到哪去）

  • CM：LPL（需 apoCⅡ 激活）水解 TG → remnant 残粒入肝
  • VLDL → IDL → LDL：LDL 经 LDL 受体把胆固醇送肝外组织
  • HDL：逆向转运胆固醇回肝（抗动脉粥样硬化），LCAT 酯化
  • 密度：CM < VLDL < LDL < HDL（直径相反）
口诀 / 提示｜口诀：『CM 外、VLDL 内、LDL 送、HDL 收』；空腹查不到 CM（半衰期 5–15 min）
氨基酸代谢 7 种
氨（NH₃）◐大纲必须掌握

⬇ 来源（从哪来）

  • 氨基酸脱氨基（联合脱氨基为主，最主要来源）
  • 肠道细菌腐败吸收（肠氨）
  • 肾小管上皮细胞分泌氨（排酸保碱）
  • 嘌呤、嘧啶分解也产氨

⬆ 去路（到哪去）

  • 肝合成尿素（主要去路，鸟氨酸循环）
  • 合成谷氨酰胺（脑、肌解氨毒形式）
  • 合成非必需氨基酸、嘌呤、嘧啶
  • 肾以 NH₄⁺ 形式排出（酸中毒时增加）
  • ⚠️ 氨有毒：肝功能受损 → 高血氨 → 肝性脑病
口诀 / 提示｜来源三路、去路四条；运氨两形式：『丙氨酸-葡萄糖循环（肌→肝）、谷氨酰胺（脑→肝/肾）』
尿素◐2021 简、2024 判

⬇ 来源（从哪来）

  • 鸟氨酸循环（肝，线粒体 + 胞液两地完成）
  • 氮源两个：一个 NH₃、一个天冬氨酸（记住！）
  • CO₂ + 2NH₃ + 3ATP（耗 4 个高能键）

⬆ 去路（到哪去）

  • 经血入肾 → 随尿排出（机体排氮废物的主形式）
  • 肠道细菌脲酶分解（少量）
  • ⚠️ 是氨解毒的终产物，不是供能物质
口诀 / 提示｜口诀：『线粒体里氨甲酰，胞液精氨代琥珀酸；氨与天冬两氮源，三 ATP 四个高能键』
谷氨酰胺○大纲必须掌握

⬇ 来源（从哪来）

  • 谷氨酸 + NH₃（谷氨酰胺合成酶，耗能）——脑、肌合成
  • 食物中蛋白质分解

⬆ 去路（到哪去）

  • 运氨到肝：水解 → 谷氨酸 + NH₃ → 尿素
  • 运氨到肾：水解供氨 → 以铵盐排酸
  • 嘌呤、嘧啶合成的氮源（与天冬氨酸并列供氮）
  • 肠黏膜、免疫细胞快速供能的燃料
口诀 / 提示｜『解氨毒的快递盒』：到哪卸货由谷氨酰胺酶决定
一碳单位◐大纲必须掌握

⬇ 来源（从哪来）

  • 丝氨酸、甘氨酸、组氨酸、色氨酸分解（口诀：施舍竹竿）
  • 形式：甲基、亚甲基、次甲基、甲酰基、亚氨甲基

⬆ 去路（到哪去）

  • 由四氢叶酸（FH₄）携带转运
  • 合成嘌呤环（N¹⁰-甲酰 FH₄ ×2）与 dTMP（N⁵,N¹⁰-亚甲 FH₄）
  • 参与 SAM 介导的甲基化反应
  • ⚠️ 叶酸缺乏 → 巨幼细胞性贫血
口诀 / 提示｜施舍竹竿（丝色甘组）＋载体 FH₄——两考合一
SAM（S-腺苷甲硫氨酸）○大纲列出

⬇ 来源（从哪来）

  • 甲硫氨酸 + ATP（甲硫氨酸腺苷转移酶）
  • 甲硫氨酸循环再生（同型半胱氨酸 + N⁵-CH₃-FH₄，需甲基 B₁₂）

⬆ 去路（到哪去）

  • 甲基转移给受体（肌酸、肾上腺素、胆碱、DNA/RNA 甲基化）→ 体内最重要活性甲基供体
  • 自身 → S-腺苷同型半胱氨酸 → 同型半胱氨酸
  • 再接受 FH₄ 的甲基 → 甲硫氨酸再生（循环）
口诀 / 提示｜『活性甲基快递员』：B₁₂ 缺乏 → 循环卡住 → 巨幼贫
GABA（γ-氨基丁酸）○2024 选

⬇ 来源（从哪来）

  • 谷氨酸脱羧（谷氨酸脱羧酶，辅酶磷酸吡哆醛/VB₆）——脑内

⬆ 去路（到哪去）

  • 抑制性神经递质（中枢神经主要抑制介质）
  • 进一步代谢进入 TCA 中间物（琥珀酸半醛 → 琥珀酸）
口诀 / 提示｜『谷氨酸脱了羧基就变温柔（抑制）』
苯丙氨酸 / 酪氨酸○2024 选、2025 选

⬇ 来源（从哪来）

  • 苯丙氨酸 →（苯丙氨酸羟化酶）→ 酪氨酸（必需转非必需的关键一步）
  • 食物蛋白质（苯丙氨酸为必需氨基酸）

⬆ 去路（到哪去）

  • 酪氨酸 → 多巴胺 → 去甲肾上腺素 → 肾上腺素（儿茶酚胺类）
  • 酪氨酸 → 黑色素（酪氨酸酶；缺乏 → 白化病）
  • 酪氨酸 → 甲状腺素
  • 酪氨酸 → 尿黑酸 → 延胡索酸 + 乙酰乙酸（生糖兼生酮）
  • 苯丙氨酸羟化酶缺乏 → 苯丙酮尿症
口诀 / 提示｜一条通路四个产物：『神经、颜色、激素、能量』
核苷酸代谢 3 种
PRPP（5-磷酸核糖-1-焦磷酸）◐2025 选（嘌呤合成原料）

⬇ 来源（从哪来）

  • 5-磷酸核糖（糖代谢来的戊糖）+ ATP（PRPP 合成酶）
  • 磷酸戊糖途径是 5-磷酸核糖的源头

⬆ 去路（到哪去）

  • 嘌呤核苷酸从头合成的起始物（IMP 合成的第 1 步底物）
  • 嘌呤/嘧啶补救合成的底物（A + PRPP → AMP；G/I + PRPP → GMP/IMP，HGPRT）
  • 参与组氨酸、色氨酸合成
口诀 / 提示｜⚠️ 注意：PRPP 是『5-磷酸核糖的活化形式』，不是 5-磷酸核糖本身
IMP（次黄嘌呤核苷酸）●2020 简、2021 简

⬇ 来源（从哪来）

  • 嘌呤从头合成的第一个核苷酸产物
  • 原料：PRPP + 天冬氨酸 + 谷氨酰胺 + 甘氨酸 + CO₂ + 一碳单位（×2）
  • 关键酶：PRPP 酰胺转移酶（committed 步骤，受 AMP/GMP 反馈抑制）
  • 补救合成：I + PRPP（HGPRT）

⬆ 去路（到哪去）

  • → AMP（需天冬氨酸供能）或 → GMP（需谷氨酰胺）
  • 分解：IMP → 次黄嘌呤 →（黄嘌呤氧化酶）→ 尿酸
  • ⚠️ 累积加重痛风：分解产尿酸 + 反馈抑制 HGPRT 阻断补救再利用
口诀 / 提示｜嘌呤原料图解口诀：『甘氨中间坐，谷酰两边挂；天冬在上方，CO₂ 卧下方；两个一碳分居 2、8 位』
尿酸●2020 简、2021 简、2024 选

⬇ 来源（从哪来）

  • 嘌呤分解终产物：AMP/GMP/IMP → 次黄嘌呤、黄嘌呤 →（黄嘌呤氧化酶）→ 尿酸
  • 人、猿、鸟类排尿酸（多数哺乳类排尿素）

⬆ 去路（到哪去）

  • 主要经肾随尿排出
  • 过高 → 尿酸盐结晶沉积关节/肾 → 痛风、肾结石
  • 治疗：别嘌呤醇抑制黄嘌呤氧化酶
口诀 / 提示｜『嘌呤的最后归宿』：酶是黄嘌呤氧化酶，药是别嘌呤醇
肝胆与血液生化 3 种
血红素◐2024 选、2025 选（原料）

⬇ 来源（从哪来）

  • 原料：甘氨酸 + 琥珀酰 CoA + Fe²⁺（三样必背）
  • 部位：骨髓（红细胞）和肝；线粒体起始 → 胞液中间 → 线粒体结束
  • 限速酶：ALA 合酶（辅酶磷酸吡哆醛），受血红素负反馈

⬆ 去路（到哪去）

  • + 珠蛋白 → 血红蛋白 / 肌红蛋白 / 细胞色素
  • 衰老红细胞破坏 → 血红素 → 胆绿素 → 胆红素（胆色素代谢起点）
  • ⚠️ 铅中毒抑制 ALA 脱水酶和亚铁螯合酶 → 贫血
口诀 / 提示｜原料三件套：『甘氨酸 + 琥珀酰 CoA + 铁』——两个来自 TCA 相关，一个来自氨基酸
胆红素◐大纲列出、黄疸必考

⬇ 来源（从哪来）

  • 血红素 →（血红素加氧酶，限速）→ 胆绿素 → 未结合（游离）胆红素
  • 脂溶性、有毒，可过血脑屏障（核黄疸）

⬆ 去路（到哪去）

  • 肝摄取 + UDPGA 结合 → 结合胆红素（水溶性、无毒）
  • 随胆汁入肠 → 尿胆原 → 部分重吸收（肠肝循环）、部分 → 尿胆素随粪排
  • 黄疸三型鉴别：溶血性（未结合↑）、肝细胞性（两者↑）、阻塞性（结合↑）
口诀 / 提示｜『未结合走血脑、结合走肠道』——水溶性一变，毒性全无
胆汁酸◐2024 判、2025 选

⬇ 来源（从哪来）

  • 肝合成：胆固醇 →（7α-羟化酶，限速）→ 初级胆汁酸（胆酸、鹅脱氧胆酸）
  • 与甘氨酸/牛磺酸结合 → 结合胆汁酸

⬆ 去路（到哪去）

  • 入肠道乳化脂肪 → 肠菌去结合/去羟 → 次级胆汁酸（脱氧胆酸、石胆酸）
  • 肠肝循环回收约 95%
  • 负反馈抑制 7α-羟化酶（胆固醇 ←→ 胆汁酸互相牵制）
口诀 / 提示｜胆固醇『第一大去路』；7α-羟化酶是限速开关
